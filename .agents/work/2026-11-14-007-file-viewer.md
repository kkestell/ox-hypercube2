# Live file viewer beside chat

## Plan

[View live files beside the chat](../plans/2026-11-14-007-file-viewer.md)

## Summary

Implemented the read-only file split, shared filesystem content subscriptions,
and session-local live snapshots, ratio, and scroll restoration before paint.
All changes are staged for review; no commits were made.

## Departures from the plan

- Existing layout.css rules needed no changes; the additional split layout is
  contained in files.css and Workbench's header slot.
- The embedded WebDriver dispatches synthetic pointer events without native
  pointer capture. A diagnostic captured pointerdown but no captured movement;
  installed driver code confirms it targets each event with elementFromPoint.
  The resize test substitutes only setPointerCapture and dispatches captured
  events to the real React handlers, restoring the method afterward. Native
  pointer capture itself has not been manually exercised.

  by `cd ui && npm run e2e -- --spec e2e/specs/files.e2e.ts` at

  replacement, close/reopen, and real IPC unwatch calls on close and deletion.
